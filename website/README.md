# CoolCreditEngine — Static Website

This repository contains the static marketing website for **CoolCreditEngine**, a compliance‑focused emissions accounting platform.  
The site is built using **plain HTML, CSS, and lightweight JavaScript**, with no frameworks or build tools required.

It is designed to communicate the high‑level value of CoolCreditEngine without exposing internal architecture, proprietary logic, or implementation details.
